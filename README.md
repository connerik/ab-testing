# Common Form — A/B testing storefront

A responsive, browser-only clothing storefront for a school A/B testing project.

## Run locally

Open `index.html` in a browser. Product photography and fonts load from Unsplash
and Google Fonts, so those need an internet connection.

## Demo features

- Switch between light and dark themes.
- Browse, filter, search, and sort the clothing collection.
- Save favorites and manage a persistent shopping bag.
- Switch between hero message variants A and B. The results panel tracks
  variant views, hero CTA clicks, and add-to-bag conversions in local storage.
- Reset experiment metrics, subscribe to the demo newsletter, and preview the
  checkout message. No customer data or payments are submitted.
